# 本次对话改动详解（完整版，含具体代码）

本文档按“最终目标 -> 文件改动 -> 关键代码 -> 验证结果”的结构，完整记录本次对话中已完成的代码变更。

## 一、最终目标与范围

本次改动聚焦于以下目标：

1. 让 LGN phase 下元学习链路走真实环境语义的可高阶追踪路径。
2. 明确区分一阶 CUDA 路径与 meta 可追踪路径的语义边界。
3. 修复 exploration 在短 rollout 下结构性失活问题。
4. 将 LGN 权重语义改为“完全无约束”：
   - 原始输出可正可负
   - 可大于 1
   - 各分量和不要求为 1
   - 训练实际使用值不做 clamp / normalize / simplex 约束

## 1) env.py

### 1.1 新增明确语义开关：use_meta_differentiable_dynamics
用途：把旧的 `use_meta_fallback` 语义升级为“LGN/meta 阶段走可高阶追踪动力学路径”。

```python
# LGN/meta phase should use the autograd-traceable dynamics path
# (run_torch + update_state_vec_torch) so higher-order gradients can flow.
self.use_meta_differentiable_dynamics = False
# Backward-compatible alias for older call sites.
self.use_meta_fallback = False
```

### 1.2 set_meta_differentiable_mode 同时写入新旧字段
用途：兼容旧调用，不破坏现有调用点。

```python
def set_meta_differentiable_mode(self, enabled):
    enabled = bool(enabled)
    self.use_meta_differentiable_dynamics = enabled
    self.use_meta_fallback = enabled
```

### 1.3 env.run 动力学函数选择改为新字段

```python
dyn_fn = run_torch if self.use_meta_differentiable_dynamics else run
```
